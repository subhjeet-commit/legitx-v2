# Open-source release checklist

- [ ] Choose and add a license (`LICENSE`). The current repository intentionally does not choose one for the copyright holder.
- [ ] Replace or review third-party assets and confirm redistribution terms for Guna UI, Fody/Costura, icons, and embedded presets.
- [ ] Review every registry preset for the supported Windows versions.
- [ ] Build from a clean checkout and publish checksums for the exact release artifact.
- [ ] Keep the security and privacy documents current when URLs, process launching, hooks, registry writes, or data collection change.
- [ ] Add a contribution guide and code-of-conduct if the project will accept outside contributions.
